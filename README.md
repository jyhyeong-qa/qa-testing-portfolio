# Quality Assurance (QA) Testing Portfolio

Welcome to my Quality Assurance portfolio. This repository showcases my end-to-end testing skills across **Manual Testing**, **Defect Reporting**, **UI Automation (Playwright)**, **REST API Testing (Postman)**, and **SQL Database Validation**.

## Repository Structure

| Folder | Focus Area | Tools & Techniques Demonstrated |
| :--- | :--- | :--- |
| `manual-testing/` | **Test Cases & Bug Reports** | ISTQB Test Design (Equivalence Partitioning, Boundary Value Analysis), Severity/Priority triage on [SauceDemo](https://saucedemo.com). |
| `automation/` | **UI End-to-End Automation** | Automated login, negative validation, and checkout flows written in **Playwright (JavaScript)**. |
| `api-testing/` | **REST API Testing** | HTTP status validation (`200`, `403`, `404`), token authentication, and Postman JavaScript assertions on [Restful-Booker](https://herokuapp.com). |
| `sql-testing/` | **Database Verification** | SQL queries (`SELECT`, `INNER JOIN`, `LEFT JOIN`, `GROUP BY`) to verify backend data integrity after UI transactions. |

## Core QA Competencies
* **Test Documentation:** Test Plans, Test Scenarios, Test Cases, and Defect Reports
* **Testing Types:** Functional, Regression, Smoke, Exploratory, Cross-Browser, API, and Database Testing
* **Technical Stack:** Playwright, JavaScript, Postman, SQL, Git/GitHub, Jira (Fundamentals)
